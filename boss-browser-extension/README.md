# BOSS 会话伴随助手（开发中）

这是原招聘项目的 Chrome Manifest V3 网页伴随端，用于在没有官方招聘消息 API 时识别已登录页面中的超时未回复会话。

## 安全边界

- 不读取、导出或上传 Cookie、Token 和密码。
- 不调用网页私有接口，不伪造指纹，不绕过验证码或风险提示。
- 新安装默认开启本机紧急停止；页面选择器不完整时失败关闭。
- V0.5 新增独立“只监测模式”并默认开启：允许脱敏诊断和消息状态同步，但扩展后台硬性拒绝发送租约，不填写输入框、不点击发送按钮。
- V0.6 新增“检测当前 BOSS 页面”：扩展可主动连接安装前已经打开的标签页；若 Chrome 拒绝注入，刷新 BOSS 页面一次后再检测。
- V0.7 改为被动 DOM 结构采集：HR 手动停留在会话页后，扩展一次性扫描顶层页面和子 iframe，只导出标签、类名、属性名、尺寸和重复关系，不自动导航、点击、输入或发送。
- V0.7.1 对重复会话项去重并优先保留编辑器、消息、未读角标和发送控件，避免长会话列表挤占右侧详情结构。
- V0.8 提供真实 BOSS 只监测预设，使用选中会话 `data-id`、`.message-item`、`.item-friend` / `.item-myself` 和本地脱敏消息摘要完成只读识别；发送按钮保持空白，不能进入发送流程。
- V0.8.1 被动统计当前已加载会话数、未读会话数和选中会话未读状态，诊断中不保存会话姓名、正文或原始 ID。
- V0.8.2 将真实 BOSS 预设改为一键直接保存，并强制开启只监测与本机紧急停止，避免表单已填写但配置未落盘。
- V0.8.3 在 `zhipin.com` 且只监测开启时运行时补齐缺失的真实选择器，兼容扩展升级遗留配置；发送按钮不会被补齐。
- V0.8.4 兼容方向标记位于消息节点自身或内部包装层，并在脱敏诊断中增加消息节点、候选人消息和 HR 消息数量。
- V0.8.5 在 BOSS 同时保留隐藏和可见聊天实例时只读取可见容器，避免命中隐藏空会话导致消息数为零。
- V0.8.6 兼容 Vue 传送或虚拟化导致消息节点脱离会话父容器：限定查询为空时回退到全页面可见消息节点，会话身份仍来自选中项 `data-id`。
- V0.9 改为左侧会话列表优先：连续两次稳定快照后，使用 `data-id`、`.badge-count`、`.time`、`.source-job` 和 `.push-text` 的 SHA-256 摘要建立本地未读观察队列；只监测阶段不再依赖右侧消息详情。
- V0.9.1 兼容会话 ID 位于列表项子节点或不暴露在 DOM 的页面：优先读取受限 ID 属性；确实没有 ID 时，以候选人、岗位和当前摘要生成仅驻留本机的复合指纹，发现碰撞即停止而不合并会话。
- V0.10 增加本地超时判定队列，将未读会话划分为“观察中”和“已超时待处理”，显示下一条预计超时时间；该状态不会触发任何页面交互或消息发送。
- V0.11 增加匿名只读待处理面板，按超时状态和未读持续时间排序，展示未读数、最近观测时间以及岗位/摘要识别状态。
- V0.12 增加默认关闭的 Chrome 本地聚合提醒；会话首次达到超时阈值时仅提醒一次，不包含候选人信息，也不会打开页面或发送招聘消息。
- V0.13 在 HR 手动选中会话后只读识别最后消息方向，并为超时未读会话显示回复资格；页面预设改为直接枚举候选人和 HR 消息包装节点。
- V0.13.1 根据脱敏结构报告将当前消息容器修正为 `.conversation-message`，并在运行时兼容迁移旧的 `.chat-conversation` 与 `.message-item` 配置。
- V0.13.2 在真实 BOSS 只监测模式固定使用已经脱敏报告验证的页面预设，避免历史自定义选择器继续覆盖消息方向节点；方向失败时明确区分“没有节点”和“节点方向未知”。
- V0.14 将已加载列表的脱敏未读快照同步到正式后端观察队列；传输内容仅包含 SHA-256 摘要、数量和时间，服务端仍保持只监测且不签发发送许可。
- 是否启用、自动发送、超时、配额、时段和回复模板均从后端账号策略读取；未配对或后端不可达时自动发送强制关闭。
- 后端先为最新来信签发单次 45 秒发送租约，发送前再等待 3 秒复核。
- 点击后必须在 DOM 中看到文本一致的外发消息才记账；结果不确定时停发且禁止自动重试。
- 多标签页使用主标签租约互斥，消息 ID 缺失、方向未知或时间无效时不猜测。
- 只填写草稿也必须取得主标签租约，一个 Chrome Profile 同一时刻只有一个会话页可执行；完成或失败后立即释放。
- Chrome 重启后不继承旧运行状态，扩展会清除主标签租约并进入安全暂停，直到 BOSS 沟通页产生新心跳。
- 页面必须连续两次产生相同会话快照才可继续；SPA 路由切换、消息列表刷新或 DOM 重绘期间不发送。
- 发送前检查输入框与按钮是否可见、可用、仍在 DOM 中且未被消息弹窗或遮罩覆盖；扩展不会自动关闭平台弹窗。
- 只对当前可见的验证码、登录失效和风险文字停机，避免隐藏模板文字造成误判；扫描设有上限以避免复杂页面卡顿。
- 本机紧急停止时仍可运行只读 DOM 诊断，但不同步消息、不填写输入框、不申请发送租约。
- 按 Chrome Profile 隔离多账号，每个 Profile 只登录一个招聘账号。
- V0.18.1 增加“采集当前岗位”：点击时立即从 HR 正在查看的 BOSS 岗位详情页读取可见的名称、地点、薪资、经验、学历和职位描述，并自动填入独立核对页，再通过当前配对账号保存为系统职位草稿。企业与账号由配对关系确定，重复岗位不再次创建；不保存页面 URL、不读取 Cookie，也不自动启用或审核岗位。

## 开发者加载

1. Chrome 打开 `chrome://extensions` 并启用开发者模式。
2. 选择“加载已解压的扩展程序”，指向本目录。
3. 在招聘控制台“自动跟进”页为目标账号生成一次性配对令牌，10 分钟内输入扩展设置页。
4. 每个 Chrome Profile 只配对一个 BOSS 账号；重新配对会撤销该账号的旧设备令牌。
5. 在获得合法的招聘端测试账号后，可在设置页用“从页面选取”学习 DOM；学习选择器时保持紧急停止开启，需要验证消息同步时关闭紧急停止但必须保持“只监测模式”开启。
6. 如果诊断一直为空，先在设置页点击“检测当前 BOSS 页面”；页面连接成功后，即使尚未配置选择器，也应看到明确的“未找到当前会话、输入框或发送按钮”诊断，而不是空白。
7. 快速录入岗位时，先在 BOSS 打开目标岗位详情，再点击扩展弹窗中的“采集当前岗位”。补齐黄色提示的字段并确认保存，随后到招聘控制台“职位资料”完成核对、回复知识审核与启用。
8. 尚未取得真实账号时，可先启动下方本地实验台，打开模拟岗位详情并点击“采集当前岗位”验收自动填表；实验数据不能绕过账号配对，也不会写入真实岗位。

## 本地会话实验台

在本目录执行 `python3 -m http.server 8091 --bind 127.0.0.1`。服务器只绑定本机，不要向局域网暴露扩展源码。

- 会话实验页：`http://localhost:8091/fixtures/boss-chat.html`，用于验证会话选择器、风险停机与只读诊断。
- 岗位采集实验页：`http://localhost:8091/fixtures/boss-job.html`，用于验证“采集当前岗位”会自动预填岗位名称、地点、薪资、薪数、经验、学历与职位描述。该页面不连接 BOSS，保存草稿仍要求已完成真实账号配对。

会话实验页的选择器配置为：

- 当前会话 `.active-chat`，会话 ID 属性 `data-conversation-id`
- 候选人 `.candidate-name`，职位 `.job-title`
- 消息 `.message`，消息 ID `data-message-id`，方向 `data-direction`，时间 `data-created-at`
- 输入框 `#editor`，发送按钮 `#send`

真实 BOSS 招聘端 DOM 尚未取得，因此选择器不会在代码中猜测或预置。

实验台已覆盖以下故障注入：

- 两个独立会话、候选人新消息、HR 人工回复和会话切换。
- 点击发送后 DOM 不产生外发消息，用于验证 `UNKNOWN` 回执和禁止重试。
- 未知消息方向、无效消息时间和 DOM 改版，用于验证失败关闭。
- 验证码和登录失效提示，用于验证风险停机。

每次修改扩展后运行 `npm test` 和 `npm run check`；实验台的状态机会与扩展共同回归。

## 只读运行诊断

扩展设置页每 10 秒刷新一次最近诊断，并保留最多 50 次状态变化。可以导出 JSON 供开发排查，也可以随时清空。

诊断中只包含：

- 页面 origin，不包含 URL 路径和查询参数。
- DOM 适配器、会话 ID 和消息 ID 的 SHA-256 摘要。
- 最后消息方向、时间、年龄、会话绑定状态与失败原因。

诊断不包含候选人姓名、消息正文、Cookie、密码、设备令牌或原始外部 ID。

扩展弹窗提供四项托管准备检查：账号连接、招聘系统在线、会话页面识别和允许执行托管。四项未全部完成时不得进入真实试发。

后端地址如果不是 localhost，保存或配对时 Chrome 会按该精确 origin 单独请求访问权限。
