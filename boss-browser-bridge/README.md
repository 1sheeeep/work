# BOSS 安全浏览器桥接

当前版本：0.37.1。在 Dashboard 开启“挂机值守”后，扩展会自动同步后端策略，立即遍历当前消息列表的全部未读，并持续监测后续新来信；只有末条来自求职者、为纯文本、未约面、唯一匹配已审核岗位并通过事实校验时才发送。扩展每分钟还会对已经打开的 BOSS 职位管理页执行一次只读稳定采集并直接同步后端，不会自行跳转或打开 BOSS 页面。扩展运行态写入已串行化，多个候选人同时来信时不会相互覆盖已入队 AI 任务；页面重载后会恢复匿名基线和待轮询任务。

插件弹窗提供“一键复制全部聊天记录”：仅处理当前选中的会话，尝试向上加载历史消息，在浏览器本机脱敏手机号、邮箱、身份证号和微信号后写入剪贴板，不上传聊天正文。

这是每个 BOSS 账号独立 Chrome Profile 中安装的最小 Manifest V3 桥接器。它用来替代会触发真实页面跳转的 CDP 只读附着方案。

## 安全边界

- 只读取已打开沟通页的会话 DOM，以及 HR 手动打开的职位列表或职位详情页；不会自动跳转或翻页。
- 在页面内将会话标识、预览和最后消息转换为 SHA-256 摘要；候选人姓名和消息正文不会上报。
- 沟通页只上传岗位标题；职位列表上传岗位名称、地点、薪资、经验和学历，职位详情页补充招聘类型、职位描述、职位类别、驻外类型、薪数、关键词和详细地址。原始平台 ID 与详情页参数只在页面内生成摘要。
- 不申请 `cookies` / `webRequest` / `debugger` / 下载权限，不读取或传输 BOSS Cookie、Token 和密码。
- 默认观测链路不执行点击、输入或发送；只有 HR 在 Dashboard 明确开启“挂机值守”后，才会进入受限发送链路。
- “只读检查回复入口”只连续核对当前会话、可见输入控件和发送按钮的结构摘要，不读取输入内容，不触发页面事件。
- “已读会话草稿测试”只能由 HR 在当前 BOSS 页面按 `Option + Shift + D` 或点击扩展按钮触发；仅允许已读会话和空输入框，写入固定测试文字，不执行点击、按键或发送。

## 本地安装（测试阶段）

1. 启动招聘值守台，确认本机 `http://localhost:8088` 或生产地址 `http://13.215.3.189:8088` 可访问。
2. 在后台“账号与浏览器”为目标 BOSS 账号生成一次性接入码。
3. 在该账号独立 Chrome Profile 中打开 `chrome://extensions`，开启开发者模式。
4. 点击“加载已解压的扩展程序”，选择本目录 `boss-browser-bridge` 。
5. 打开扩展弹窗，确认后台地址后粘贴一次性接入码完成配对。
6. 在同一 Profile 中由 HR 手动登录 BOSS，打开沟通页并刷新一次。

配对后，弹窗会显示当前识别到的 BOSS 工作页面。“进入对应工作页”只会新开本机招聘值守台：沟通页进入消息值守，职位列表或详情进入岗位资料，其他情况进入招聘账号。该功能不会改变 BOSS 页面或读取完整 URL。

## 同步职位资料

1. 在对应招聘账号的独立 Chrome Profile 中手动进入 BOSS“职位管理”。
2. 等待当前页岗位列表加载稳定，打开扩展并点击“同步当前职位页”。
3. 如需完整信息，由 HR 手动打开某个岗位的编辑详情页，等待表单加载完成，再点击同一个“同步当前职位页”。
4. 回到招聘值守台“岗位资料”，点击“刷新同步结果”，展开岗位行查看详情。
5. 逐项核对采集草稿；人工核对并审核前不会启用或参与回复。

如果列表有分页，由 HR 手动切换后逐页同步，后端会按账号、来源摘要和规范化标题去重。页面缺少稳定 ID、字段仍在变化、登录失效或出现风险验证时，采集会立即停止。

多账号部署时，每个 Profile 都单独加载一次此目录，并使用对应账号的一次性接入码。

## 回复页面人工验收准备

1. HR 手动进入 BOSS 沟通页，打开一个允许测试的已读会话。
2. 确认页面没有验证码、风险提示或登录失效。
3. 在 BOSS 页面直接按 `Option + Shift + R` 是推荐方式，不会因打开扩展弹窗而让网页输入框失去焦点；也可在弹窗点“只读检查回复入口”。扩展会连续检查 3 次，只向后端提交会话和控件的 SHA-256 摘要。
4. 检查通过后，到“值守规则与记录 → 页面能力与受控动作”开启 10 分钟单次人工验收。真实点击、输入和发送仍必须由 HR 手动完成。

## 已读会话草稿写入测试（不发送）

1. HR 手动进入 BOSS 沟通页并打开一个允许测试的已读会话；扩展不会代替 HR 切换会话。
2. 确认回复输入框为空，页面没有验证码、风险提示或登录失效。
3. 在 BOSS 页面按 `Option + Shift + D`，或在扩展弹窗点击“写入测试草稿（不发送）”。
4. 扩展连续确认同一会话、已读状态和同一回复入口后，只填入固定文字“【草稿测试，不会自动发送】您好，已收到您的消息。”。
5. HR 目视确认文字出现在输入框且页面没有新增外发消息，然后手动清空输入框。

该测试不接入后台无人值守队列，不获取发送租约，不点击发送按钮，也不会用 Enter 键提交。输入框已有内容、会话仍未读、页面状态变化或风险校验出现时均直接停止。

## 已审核安全草稿填入（不发送）

1. HR 先在招聘值守台审核通过企业/岗位知识完整的安全草稿。
2. HR 手动打开对应会话，确认最后一条仍为候选人来信、输入框为空且页面无风险提示。
3. 在 BOSS 页面按 `Option + Shift + F`，或在扩展弹窗点击“填入已审核安全草稿”。
4. 后端只返回当前知识版本下的已审核正文，凭据 60 秒后失效；页面脚本再次核对会话、控件和草稿 SHA-256 摘要后才填入。
5. 成功后扩展和工作台只标记“已填入未发送”，仍由 HR 目视检查并手动处理。

该链路没有发送指令，不点击发送、不模拟 Enter、不后台轮询。会话切换、输入框已有内容、草稿版本变化、凭据过期或回执丢失时都会失败关闭；结果不确定时禁止自动重试。

## 当前会话单次发送测试（真实发送）

1. 只在允许测试的已读会话中保留固定草稿“【草稿测试，不会自动发送】您好，已收到您的消息。”。
2. 保持该会话当前选中，不打开、不切换其他会话。
3. 打开扩展弹窗，点击“发送当前测试草稿”，阅读不可撤回提示后二次确认。
4. 扩展连续三次核对同一会话、同一输入框、完全一致的固定文本和唯一发送按钮，然后最多点击一次。
5. 只有输入框清空且当前会话末条出现相同 HR 外发文字时才显示成功；否则显示“结果未知”并停止。

该测试没有快捷键、后台调度、会话切换、Enter 发送或重试路径。一旦发生真实点击，测试入口会持久锁定；测试通过也不会开启其他会话或无人值守发送。

发送按钮识别只在当前选中会话容器内进行，会同时读取可见文字以及图标按钮的 `aria-label`/`title`。系统只保留请求操作标签的摘要；不记录原始 DOM、图片或消息正文。若发现多个可能发送按钮、只有图标但无可访问标签，或按钮不在当前会话容器内，测试会直接停止。

真实页面 0.8.4 适配只接受当前回复框所属 `.conversation-editor` 内唯一的 `.submit-content > .submit.active` 作为发送节点，并再次核对可见、指针状态、禁用祖先和“发送”文字。外层 `.submit-content` 仅作为容器，禁止点击；全局同名节点、非激活节点或多个匹配均失败关闭。

## 当前会话功能键 DOM 诊断（只读）

HR 保持一个会话选中后，可在扩展弹窗点击“识别当前会话功能键 DOM”。扩展只在该会话输入区附近扫描可见交互控件，记录标签名、受限类名、角色、尺寸、禁用状态、图标类名和有限父级路径，用于适配“发送、求简历、换电话、换微信、约面试”。报告不包含原始 HTML、输入值、消息正文、候选人姓名、链接、Cookie 或平台原始 ID，不上传后端；只有 HR 主动点击“复制脱敏报告”才会进入剪贴板。诊断过程不点击、不聚焦、不切换会话、不发送。

0.8.5 可在 `.operate-btn` 等受限交互节点上将带有附加状态文字的标签归类为“求简历、接收简历、换电话、换微信、约面试、不合适、发送”，但不会输出附加原文。带 `.disabled` 或禁用祖先的操作只能报告，禁止进入点击测试。三类外部动作必须分别在 HR 手动打开的当前会话中进行单次验收，不能串行点击或按页面排列位置猜测按钮用途。

0.9.0 为“求简历、换电话、换微信”增加三个彼此独立的当前会话入口测试。每项必须由 HR 在弹窗中单独二次确认，连续三次核对同一已读会话及唯一可用 `.operate-btn` 后最多点击一次，并立即持久锁定。若平台显示确认弹窗，扩展只报告弹窗已打开，不点击确认；页面状态不明或通信中断时保持锁定且不重试。该入口测试不等同于生产自动执行能力。

0.9.1 在只读 DOM 诊断中纳入当前可见平台弹窗及其可见交互控件，并只对白名单“确认、确定、取消、暂不”返回操作类别。弹窗正文、候选人信息及其他文字仍只生成摘要，不输出原文；诊断不会点击确认或取消。

0.9.2 对 `.boss-btn` 与 `.card-btn` 增加确认/取消类别识别，并为二级控件增加受限 `ownerAction`，只允许标记其属于求简历、换电话、换微信或约面试。该字段通过最近 `.operate-icon-item > .operate-btn` 的白名单语义计算，不依赖兄弟顺序，也不包含页面原文。

0.9.3 增加换电话与换微信各自独立的二级确定测试：必须同时证明当前会话、所属 `.operate-icon-item`、唯一 `.boss-btn-primary` 确定按钮和唯一 `.boss-btn-outline` 取消按钮连续三轮稳定，才允许 HR 二次确认后点击一次确定。两个动作分别持久锁定，通信中断或结果未知不重试；求简历消息卡片不会复用该定位器。

0.9.4 将已通过脱敏结构识别的“约面试”纳入当前会话入口单次测试。它只点击当前 `.operate-exchange-left` 中唯一、可见、未禁用且语义为约面试的 `.operate-btn`，随后停在平台面试设置界面；不选择时间、地点或面试方式，不填写信息，也不确认邀约。

0.9.5 根据首次点击后的脱敏证据，将“约面试”真实点击节点收窄为唯一 `.operate-btn > .interview`。仅当同一份本机诊断证明外层入口仍可用、内部节点唯一可见且两者标签摘要一致，并且上次结果明确为 UNKNOWN 时，升级过程才会只解除一次约面试锁；其他操作锁不受影响。该验收仍只尝试打开设置界面，不填写或确认邀约。

0.9.6 为已打开的真实面试邀请窗口增加只读字段分类：岗位、地址、备注、日期、时间、面试方式选项、联系人、取消和发送。诊断只返回字段类别及面试方式是否选中，不读取或输出岗位值、地址、备注、日期、时间、联系人或候选人信息，也不点击和填写任何字段。

0.9.7 新增 `Option + Shift + I` 静默 DOM 诊断快捷键。它直接由扩展后台向当前 BOSS 标签页发起只读采集，不打开扩展弹窗，因此可在日期、时间、岗位或联系人下拉层保持展开时记录其脱敏结构；采集完成后再打开扩展复制报告。快捷键不点击、选择或填写任何页面控件。

0.9.8 将面试弹窗内的只读扫描范围补充到日期面板单元格、日期标题/翻页节点，以及岗位、时间、联系人容器中的选项类节点。该扩展范围只在已识别的 `.interview-invite-dialog-ui` 内生效，继续只返回受限类名、尺寸和文字摘要，不返回日期或选项原文。

0.12.4 兼容 BOSS 当前页面将电话和面试入口显示为“查看电话”和“查看面试”。扩展只将这两个可见文案归一到原有电话/面试内部动作，不放宽唯一节点、已读会话、单次锁定或二级确认要求。

0.13.0 补齐生产“索要简历”页面执行器。扩展只在 BOSS 沟通页为当前活动页、当前会话已读、会话摘要与后端任务完全一致，且 `REQUEST_RESUME` 已通过真实页面验收、双人生产批准和限额校验时领取 30 秒单次租约。页面连续三轮核对后各点击一次“求简历”与唯一确认按钮；若通信、会话、弹层或结果不明，立即停止、回传 `UNKNOWN` 并冻结账号，永不自动重试。默认 `APP_BROWSER_MONITOR_ONLY=true` 仍会禁用所有生产写动作。

0.14.0 增加选中会话的只读阶段信号：仅判断“求/查看简历、换/查看联系方式、约面试、面试已确认”等控件是否可见可用，不读取联系方式或候选人正文。后端持久化信号并推断阶段；只有阶段明确为 `CAN_REQUEST_RESUME` 的会话才能创建和领取索要简历任务，已出现“查看简历”后不会重复索要。

0.15.0 增加职位生命周期同步：职位管理页保持打开时，页面稳定变化会触发只读同步；读取每个可见岗位的在招/关闭状态，BOSS 明确显示关闭时立即同步下架。仅当扩展确认当前是无后续分页的完整“在招职位”清单时，缺失岗位才进入二次确认，12 秒后再次读取仍缺失才自动关闭，避免页面未加载完或分页导致误下架。重新开放的岗位只恢复为待核对草稿，不会直接启用自动回复。

0.16.0 增加显式启动的单会话完整周期测试执行器：同一匿名会话可在已读、稳定选中后依次执行经 HR 确认的安全回复、BOSS 原生求简历、简历人工复核、微信优先/电话兜底的联系方式交换。每个写动作仍采用 30 秒单次租约、三轮目标稳定校验、一次点击与不可逆摘要回执；任何未知结果都会冻结自动动作。面试安排始终交由 HR 人工完成。

## Dashboard 统一挂机自动回复（0.33.0）

1. 只保留一个已登录当前配对账号的 BOSS 沟通页，并确认招聘值守台后端健康。
2. 在招聘值守台 Dashboard 选择 2 小时、4 小时或全天，开启挂机；扩展不再提供第二个启停入口。
3. 开启时立即将当前消息列表全部未读纳入处理，并持续监听新增/变化的未读会话与当前已打开会话的末条消息变化。每个会话必须连续稳定复核，且最后一条是候选人纯文本、尚未约面才会进入 AI 队列。
4. 后端先完成岗位匹配和消息分类；只有已审核岗位资料能够回答、置信度达到阈值且不涉及敏感或岗位无关内容时，才生成不超过 90 字的确定性回复。
5. 扩展再次核对会话、末条消息、空输入框和唯一发送按钮后点击一次，并以输入框清空和末条外发文字共同确认结果。
6. Dashboard 关闭挂机或托管时段到期后，扩展会自动终止循环。页面出现登录/风控状态、输入框已有 HR 草稿、DOM 身份不稳定、发送结果不明或每小时达到 20 条时，系统会失败关闭或禁止重试。

该模式仅作用于接入码所配对的一个账号，不做跨账号调度。最近 200 条匿名“会话摘要 + 消息摘要”会保存在扩展本地用于防重复；公开状态只显示数量，不返回摘要内容。
