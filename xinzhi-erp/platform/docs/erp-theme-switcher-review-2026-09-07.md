# ERP 可切换主题（本地，未部署）

用户同意将已讨论的方案做成可切换主题。默认奶杏燕麦，共 9 款：奶杏燕麦、蜜桃奶油、玫瑰奶茶、香草焦糖、瓷白石墨蓝、暖白深青、中性商务蓝、雾白石墨灰、浅白鼠尾草绿。

## 实现范围

- 右上角账号设置 → 界面主题，原生带标签 select，附当前底色/选中色/主色小样；支持现有中英文界面。
- 仅切换根元素 data-erp-theme，复用同一套布局和语义 CSS 变量，不刷新页面、不重新挂载业务组件，不新增依赖、配置接口或数据库字段。
- 浏览器偏好键 xz-erp.theme；在 React 初次渲染前恢复白名单内的已保存主题。无保存值/非法值回退奶杏燕麦；存储被禁止时仍应用主题，并提示不能持久保存。是浏览器偏好，不是账号、企业或跨设备配置；已打开的其他标签页在刷新后读取偏好，不进行实时广播。
- 统一按钮、链接、导航、筛选、选中行、表头、表单及 portalled 弹窗色板；错误/警告/成功语义色不变，图片、打印尺寸、报表区分色、业务合同、权限及路由不变。
- 以 [Carbon 语义变量与主题机制](https://carbondesignsystem.com/elements/themes/overview/) 为实现模式参考，复用本项目 CSS/React/原生控件，不引入 Carbon 依赖或照搬色板。
- 原先“无主题开关”的本地测试约束由用户本轮明确要求替代。旧单一色板断言已改为 9 款覆盖、语义状态不变及逐款对比度约束。
