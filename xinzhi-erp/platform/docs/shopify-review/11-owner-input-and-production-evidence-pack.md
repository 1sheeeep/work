# Level 2 负责人填写与生产证据采集包

本文件用于把 Shopify Level 2 审核中必须由公司、法务、安全或运维负责人确认的事项一次收齐。它不是法律意见，也不是已完成声明。未取得真实决定或生产证据时保持空白，禁止猜测。

## 安全边界

- 开户方式已由用户确认，不再待决：任何用户、任何企业均须由我们开通账号并授权才可使用，不开放公众自助注册；安装 Shopify 应用不授予系统使用资格。负责人需预先核准并准备隔离审核账号，记录正常授权范围，不设置审核后门，不等待审核员安装后再临时审批。该决定不等于 Shopify 已批准具体入驻模式。

- 不在 Git、审核说明或截图中保存真实密码、访问令牌、密钥、数据库连接串、未脱敏客户数据或内部网络地址。
- 审核账号密码通过公司批准的安全渠道交付，只在 Partner Dashboard 的受限审核字段填写。
- 生产截图只保留控制名称、启用状态、环境、区域和时间；客户姓名、地址、电话、邮箱、订单号及账号标识必须遮盖或使用合成数据。
- 原始证据保存在公司批准的受限资料库；本仓库只记录证据编号、结论、负责人和脱敏副本位置。

## 每份证据的验收字段

每个证据编号必须同时记录：

- 证据编号和控制名称；
- 精确生产环境与应用版本/部署标识；
- 采集日期、时区和采集人；
- 可见的“已启用”状态、适用资源和区域；
- 脱敏说明及受限原件位置；
- 负责人的确认日期；
- 若为周期性控制，最近一次执行日期和下一次计划日期。

缺少任一字段时，该证据仍视为未完成。开发环境、示例配置、代码实现或口头说明不能替代生产证据。

## Partner Dashboard Level 2 填写边界

- 只申请姓名、地址、电话和邮箱四项。
- 用途只写商户订单履约、配送联系和订单特定支持。
- 不写广告、画像、获客、营销或与订单无关的客户分析。
- OAuth scope 已在 `03-access-and-protected-data.md` 冻结为十项完整的当前版本 Shopify 集成权限；`read_all_orders` 具有历史订单最小真实演示模块并已获批。两个拒付证据受限 scope 因合作伙伴组织未满一年而被拒，本版本不申请、不实现也不宣称证据读写。Level 2 字段申请是独立的数据保护审批，不能替代任何 API scope，也不能扩大用途。
- 提交前确认 listing、隐私政策、审核说明和产品实际行为使用同一套用途描述。

## 交付顺序

1. 公司/法务完成 `OWN-*` 决策并批准公开文案。
2. 法务/隐私负责人完成 `L1-*` 适用性及协议证据，运维/安全采集 `L2-*` 生产证据，并完成脱敏和负责人确认。
3. 系统管理员创建独立审核账号，并通过安全渠道提供密码。
4. 产品负责人完成精确版本的中文界面截图、带准确英文字幕的录屏和公开录屏 URL。
5. 工程负责人对精确部署版本重跑全部门禁和负向测试。
6. Partner 所有人运行后台自动检查；所有必填项和 protected data 申请无缺项后才可提交。

## 停止条件

只要任一 `OWN-*` 信息未确认、任一 `L2-*` 证据未验收、仍存在 `{{...}}` 占位符，或精确提交版本尚未完成复测，就不得标记 Level 2 材料完成，也不得点击 Submit。
