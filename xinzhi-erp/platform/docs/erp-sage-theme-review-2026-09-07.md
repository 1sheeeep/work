# 暖白 / 鼠尾草绿正式主题 · 2026-09-07

用户确认本地框架、商品列表及编辑弹窗样板后，授权推广到 ERP 并按既有流程部署。本轮只调整前端呈现；不使用 UI/UX Max，不修改业务路由、数据合同、权限或生产客服。

## 实现

- `erp-theme.css` 作为最后加载的正式颜色与质感规范；原公共设计层继续负责结构、控件尺寸和交互。移出其旧蓝色令牌，避免两个主题定义竞争。
- 暖白工作区、浅灰绿侧栏、深灰绿正文与主按钮；表格、筛选、选中态、分页、快捷导航、账号菜单、表单弹窗及登录页采用相同色板。
- 将已跟踪样式中的旧蓝/冷灰文字、边界、背景和焦点引用迁到语义变量；保留错误红、警告黄、成功状态与报表数据区分色，不改图片、Logo 或打印尺寸。
- 复用现有原生表格、表单、排序、分页、权限过滤与焦点逻辑，没有新增依赖。结构参考 [Carbon 数据表模式](https://carbondesignsystem.com/components/data-table/usage/)，色对依据 [WCAG 对比度规则](https://www.w3.org/TR/WCAG22/)。不宣称整个应用达到完整无障碍认证。
- 样板 CSS 与 `--sage` 注入开关已由正式主题替代；没有持久化主题偏好、生产预览横幅或重复维护旧色板。本轮生成的一次性机械迁移脚本已清理。
- 本地夹具保留 10 条合成商品，另有 `--signed-out` 仅供登录页展示检查。写入 405、未知接口 503、禁用代理与环境文件读取，不接触真实凭据。
