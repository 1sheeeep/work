# 主商品往返与 URL 参数修复 · 2026-09-07

## 本轮范围

继续既有 ERP 前端便捷性优化，闭合主 SKU 列表 → 新增/详情/编辑 → 列表的一轮改进。未使用 UI/UX Max；没有修改业务接口、权限、数据库或生产客服。已有未保存离开保护不变。

- 返回路径只保留主商品列表的状态、关键词、页码、每页条数、搜索字段、类目、创建人、创建日期与排序；不携带子 SKU、编辑模式或其他模块参数。
- 详情面包屑、当前模块侧栏和功能查找采用同一个列表返回路径；切换到其他商品视图仍清除不相关条件。
- 真实浏览器发现 TanStack 默认 JSON 搜索参数规则会把导航传入的字符串 `50` 编成 `%2250%22`，导致现有 URLSearchParams 业务解析恢复默认条数。使用已有路由依赖的 parseSearchWith/stringifySearchWith 配置保持普通查询参数格式，没有增加依赖。
- 字面关键词（数字、布尔词、引号、JSON 外形、中文和 &）不因路由跳转被改写；登录重定向校验仍拒绝外站与重复 redirect 参数。

实现对照：[TanStack 自定义搜索参数序列化](https://tanstack.com/router/latest/docs/guide/custom-search-param-serialization)。保留参数采用明确白名单，不全局复制跨模块查询条件。
