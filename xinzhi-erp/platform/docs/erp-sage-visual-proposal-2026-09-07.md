# 暖白与鼠尾草绿 · ERP 视觉样板

状态：样板已获用户确认，正在推广为正式主题。本文保留样板阶段证据；当前实现与检查见 `erp-sage-theme-review-2026-09-07.md`。

## 已确认的任务

用户提供柔和暖白/浅绿手机界面参考，确认先制作整体框架、商品列表和编辑弹窗的实际样板。保留 ERP 表格密度与业务功能，不复制参考的品牌、照片、文案或手机用品架布局；不使用 UI/UX Max。后台数据表模式参考 [Carbon 数据表用法](https://carbondesignsystem.com/components/data-table/usage/)：保留搜索、筛选、排序、批量操作及分页语义，不替换现有组件库。

## 样板内容

- 暖白内容面板、浅灰绿导航、低饱和绿色选中态、深灰绿色正文；红色危险语义保留。
- 整体框架、主 SKU 列表、搜索筛选、选中行、表格操作和分页。
- 使用现有“批量修改主 SKU”弹窗展示浅绿面板、暖白输入区、两列字段和主次按钮，不改变单条主商品编辑仍为独立页面的行为。
- 样板专用 CSS 只由本地夹具的 `--sage` 开关加载；生产 main.tsx 未导入，无线上开关、偏好存储或后端修改。
- 10 条明确标识的合成商品，无真实账号、店铺或业务写入；所有 API 写入 405，未知 GET 503，没有代理和环境文件读取。

## 查看与复现

样板原先使用 `--sage` 加载；正式合并后已移除该开关。当前在 ERP 根目录运行 `node platform/scripts/erp-ui-browser-fixture.mjs`，打开终端输出地址的 `/products?view=master`，使用正式主题与 10 条合成商品。

查看编辑弹窗：勾选一行 → 批量处理功能 → 批量修改主 SKU → 勾选中文名称/商品备注。可填写本地草稿并取消；不会保存到业务系统。

- 桌面 1600 与 1440 宽、手机 390×844 的真实浏览器检查。390 宽整页无横向溢出，编辑框 clientWidth/scrollWidth 均 334；表格保持内部横向滚动。
- 搜索“背包”显示 1 条，选中行、打开并取消编辑通过；最终恢复 10 条完整列表。
- 弹窗长字段两列排列，无相邻字段重叠；原生复选框、文字提示和焦点轮廓保留。
- 颜色与隔离检查 3 项通过：主要正文/说明/操作色在指定表面上对比度 ≥4.5，输入边界/焦点色对表面对比度 ≥3，入口不导入样板。此为指定色对检查，不宣称全应用无障碍合规。
