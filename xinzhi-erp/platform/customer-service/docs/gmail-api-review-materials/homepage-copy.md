# Xzdesk Mail

Xzdesk Mail 是 Xzdesk Agent 的邮件渠道，用于帮助店铺客服集中查看客户邮件、理解客户问题并准备回复内容。

## 功能说明

Xzdesk Mail 可在用户明确授权后读取 Gmail 邮箱中的未读客服邮件，并在 Xzdesk Agent 中展示邮件主题、发件人、时间和邮件正文内容。软件会把同一邮件线程中的历史往来整理成便于客服阅读的对话视图，帮助客服更快理解客户问题。

Xzdesk Mail 不会通过 Gmail API 发送邮件。客服回复仍在 Gmail 网页中完成，由用户在自己的浏览器会话中确认并发送。

## Gmail 数据使用

Xzdesk Mail 只使用 Gmail 只读权限读取用户授权邮箱中的邮件内容，目的包括：

- 展示未读客服邮件
- 帮助客服查看邮件历史往来
- 辅助生成客服回复草稿
- 提高客服处理效率

Xzdesk Mail 不会出售 Gmail 数据，不会将 Gmail 数据用于广告，不会与第三方共享 Gmail 数据。

## 用户控制

用户可以随时在 Google Account 设置中撤销 Xzdesk Mail 的 Gmail 授权。撤销授权后，Xzdesk Mail 将无法继续读取该 Gmail 邮箱。
