# Privacy Policy

Effective date: `[日期]`

This Privacy Policy explains how `[公司/个人名称]` handles data in the desktop application "Xzdesk Mail" inside Xzdesk Agent ("the App").

## 1. What the App does

The App is the email channel for Xzdesk Agent, a local desktop customer service assistant. It helps customer service staff view customer emails, understand customer issues, and prepare reply drafts.

When a user connects a Gmail account, the App uses Gmail API read-only access to read customer support emails authorized by the user.

The App does not use Gmail API to send emails. Email replies are sent by the user through the Gmail web interface.

## 2. Google user data accessed

The App may access the following Google user data after the user grants permission:

- Gmail message metadata, such as sender, subject, received time, and thread ID
- Gmail message body content
- Gmail thread history related to the unread support email being processed

The App requests the following Gmail API scope:

`https://www.googleapis.com/auth/gmail.readonly`

## 3. How Google user data is used

Google user data is used only to provide customer service features inside the App:

- Display unread customer support emails
- Display email thread history for customer service review
- Help the user understand the customer issue
- Help generate or prepare reply drafts locally in the customer service workflow

The App does not use Google user data for advertising, marketing profiling, or user tracking.

## 4. Data sharing

The App does not sell Google user data.

The App does not share Google user data with third parties except when required to provide the user-requested service or when required by law.

Google user data is not transferred to advertising platforms, data brokers, or unrelated third-party services.

## 5. Data storage

The App is designed as a local desktop application. Gmail data and authorization tokens are stored locally on the user's computer unless the user explicitly configures another storage location.

Storage location:

`[数据保存位置说明]`

The App stores only the data needed to display customer service conversations and maintain authorized access.

## 6. Data retention and deletion

Users may delete locally stored application data from the App data directory or uninstall the App.

Users may revoke Gmail access at any time from their Google Account permissions page:

https://myaccount.google.com/permissions

After access is revoked, the App can no longer read Gmail data for that account.

## 7. Limited use disclosure

The App's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

The App will only use Google user data to provide or improve user-facing customer service features that are clearly visible in the App.

The App will not use Google user data for advertising, will not sell Google user data, and will not allow humans to read Google user data except when necessary for security, support, legal compliance, or with the user's explicit permission.

## 8. Security

We use reasonable technical and organizational measures to protect user data. Users should keep their computer, operating system, browser profile, and Google account secure.
